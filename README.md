# Authenticated - Home Assistant Custom Component\n\n[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/integration)\n\nA Home Assistant custom component to track and notify on successful logins from new IP addresses.\n\n> **This is a maintained fork of [rarosalion/authenticated](https://github.com/rarosalion/authenticated)** with critical fixes for Home Assistant 2024.9+ compatibility.\n\n## Why this fork?\n\nThe upstream repository uses `async_create()` from `homeassistant.components.persistent_notification` directly in a synchronous context. Since HA 2024.9, this causes:\n\n- `RuntimeError: Detected code that calls async_create from a thread`\n- `AttributeError: module has no attribute async_create` (HA 2025.x+)\n\nThis fork fixes the issue by using the thread-safe `hass.create_task(hass.services.async_call(...))` pattern.\n\n## Installation\n\n### HACS (Custom Repository)\n\n1.
